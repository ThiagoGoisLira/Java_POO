# ☕ Curso de Java POO - Gustavo Guanabara

Repositório dedicado aos códigos, exercícios e projetos desenvolvidos durante o **Curso de Programação Orientada a Objetos em Java** do Professor Gustavo Guanabara (Curso em Vídeo).

---

## 📚 Sobre o Curso
O curso tem como objetivo ensinar os conceitos fundamentais da Programação Orientada a Objetos (POO) utilizando a linguagem Java, abordando desde a criação de classes e objetos até pilares avançados como Herança, Polimorfismo, Encapsulamento e Interfaces.

---

## 📂 Estrutura de Pastas

As aulas e projetos estão organizados da seguinte forma:

*   `Aula 02/` - O que é um Objeto? / Criando Classes e Objetos em Java
*   `Aula 03/` - Conote de Visibilidade (Público, Privado e Protegido)
*   `Aula 04/` - Métodos Especiais (Getters, Setters e Construtores)
*   `Aula 05/` - Exemplo Prático (Conta Bancária)
*   `Aula 06/` - Encapsulamento (Interfaces)
*   `Aula 07/` - Relacionamento entre Classes (Ex: Ultra Emoji Combat)
*   `Aula 08/` - Agregação entre Objetos
*   `Aula 09/` - Exercício Prático de POO
*   `Aula 10/` - Herança (Parte 1)
*   `Aula 11/` - Herança (Parte 2)
*   `Aula 12/` - Polimorfismo (Parte 1)
*   `Aula 13/` - Polimorfismo (Parte 2)
*   `Projeto Final/` - Projeto Integrador do Curso


---
